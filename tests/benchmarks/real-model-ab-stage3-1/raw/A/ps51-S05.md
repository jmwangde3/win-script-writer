# Windows PowerShell 5.1 双击显示中文

将下面完整内容保存为 `H:\work\部署\deploy.ps1`，文件编码选 **UTF-8（带 BOM）**。Windows PowerShell 5.1 会把带 BOM 的脚本按 UTF-8 读取；没有 BOM 的 UTF-8 中文可能会被按系统 ANSI（简体中文通常为代码页 936）误读。

```powershell
#Requires -Version 5.1
[Console]::OutputEncoding = [System.Text.Encoding]::GetEncoding(936)

Write-Host '开始部署'

# 在这里执行部署步骤

Write-Host '部署完成'
Read-Host '按 Enter 键关闭窗口'
```

保存时可在记事本选择“另存为”，文件名填 `H:\work\部署\deploy.ps1`，编码选“UTF-8”（Windows 10/11 记事本该选项带 BOM）。也可以在 VS Code 状态栏点编码，选择“通过编码保存”，再选“UTF-8 with BOM”。双击脚本后会显示“开始部署”和“部署完成”；最后一行让窗口停住，方便查看完成状态。脚本将控制台输出编码设为简体中文 Windows 常用的 936。
