# 在中文 Windows 上创建可双击运行的 `deploy.ps1`

Windows PowerShell 5.1 读取 `.ps1` 时，无 BOM 的 UTF-8 会按系统 ANSI 代码页（简体中文 Windows 通常为 936）解析，中文可能变乱码。把脚本保存为 **UTF-8 with BOM**，并明确设置控制台输出编码为 936，可让中文提示正确显示。

在 Windows PowerShell 5.1 中运行下面这段完整代码。它会创建 `H:\work\部署\deploy.ps1`，并以 UTF-8 BOM 写入脚本：

```powershell
$directory = 'H:\work\部署'
$path = Join-Path $directory 'deploy.ps1'

if (-not (Test-Path -LiteralPath $directory)) {
    New-Item -ItemType Directory -Path $directory -Force | Out-Null
}

$script = @"
#Requires -Version 5.1
[Console]::OutputEncoding = [System.Text.Encoding]::GetEncoding(936)

Write-Output '开始部署'

# 在这里添加部署操作

Write-Output '部署完成'
"@

$utf8Bom = New-Object System.Text.UTF8Encoding($true)
[System.IO.File]::WriteAllText($path, $script, $utf8Bom)
```

之后双击 `H:\work\部署\deploy.ps1` 即可看到“开始部署”和最后的“部署完成”。如果需要让窗口在脚本结束后保持打开，可在最后另加 `Read-Host '按回车键关闭窗口'`；这不影响中文编码。
