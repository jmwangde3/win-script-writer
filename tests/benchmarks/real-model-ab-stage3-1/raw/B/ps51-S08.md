# Windows PowerShell 5.1 部署脚本

将下面内容保存为 `H:\work\部署\deploy.ps1`，文件编码选 **UTF-8（带 BOM）**。PowerShell 5.1 会按 BOM 正确读取脚本中的中文；脚本同时把控制台输出编码设为 UTF-8，避免双击运行时中文提示乱码。

```powershell
#Requires -Version 5.1

# 让 PowerShell 控制台用 UTF-8 显示脚本输出的中文。
[Console]::OutputEncoding = New-Object System.Text.UTF8Encoding($false)

Write-Host '开始部署'

try {
    # 在这里添加实际部署命令。
    Write-Host '部署步骤已执行。'
    Write-Host '部署完成：成功'
    exit 0
}
catch {
    Write-Host ('部署完成：失败（{0}）' -f $_.Exception.Message) -ForegroundColor Red
    exit 1
}
```

在资源管理器中双击 `deploy.ps1` 时，Windows 可能会按系统策略阻止脚本运行；需先确保该 `.ps1` 的默认打开方式是 Windows PowerShell 5.1。若成功运行，窗口会显示“开始部署”和“部署完成：成功”；发生异常时会显示失败状态并返回退出码 `1`。
