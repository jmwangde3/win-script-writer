# Windows PowerShell 5.1 中文输出脚本

把下面内容保存为 `H:\work\部署\deploy.ps1`，文件编码选 **UTF-8（带 BOM）**。BOM 让 Windows PowerShell 5.1 按 UTF-8 解析脚本里的中文；在简体中文 Windows 的中文控制台中，提示会按控制台代码页显示。

```powershell
#Requires -Version 5.1
$ErrorActionPreference = 'Stop'

Write-Output '开始部署'

# 在这里放置部署步骤

Write-Output '部署完成'
Read-Host '按 Enter 键关闭窗口'
```

确保保存时实际写入 UTF-8 BOM（文件开头字节为 `EF BB BF`），然后在资源管理器中双击 `deploy.ps1`。最后的 `Read-Host` 会让窗口停留，便于看到完成状态。若双击只是在编辑器中打开脚本，应通过 Windows PowerShell 5.1 启动它；脚本文件关联由 Windows 设置决定。
