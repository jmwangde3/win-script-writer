# build.bat

将下面内容保存为 `H:\工作\发布\build.bat`：

```bat
@echo off
chcp 65001 >nul
rem 中文参数示例：把第一个参数打印出来
echo 参数：%~1
"%~dp0build.exe"
set "BUILD_RC=%ERRORLEVEL%"
echo 构建完成
exit /b %BUILD_RC%
```

文件编码保存为 **UTF-8 无 BOM**，换行符使用 **CRLF**。不要添加 BOM：`cmd.exe` 不会把 BOM 当作文件标记，可能导致第一条命令失效。

脚本第一条命令是纯 ASCII 的 `chcp 65001 >nul`，因此无论启动时控制台代码页是 936 还是 65001，都能先执行这条命令；它将当前控制台代码页切换为 65001。其后的批处理中文字节按 UTF-8 读取和输出。脚本用 `%~dp0` 以批处理文件所在目录定位 `build.exe`，因此中文目录名不需要在脚本中硬编码。

例如从该目录调用 `build.bat 发布说明`，会打印参数和「构建完成」。脚本在运行程序后立即保存其退出码，随后打印完成提示，最后用 `exit /b` 原样返回保存的退出码（此例为 7）。
