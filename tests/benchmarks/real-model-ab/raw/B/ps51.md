# Windows PowerShell 5.1 中文脚本

把下面内容保存为 `H:\work\部署\deploy.ps1`，并在保存对话框中选择 **UTF-8 with BOM（带 BOM 的 UTF-8）**。Windows PowerShell 5.1 会依据 BOM 正确解析中文；不要保存成无 BOM 的 UTF-8。

```powershell
#Requires -Version 5.1

Write-Host '开始部署'
# 在这里执行部署操作

Write-Host '部署完成'
Read-Host '按 Enter 键关闭窗口'
```

最后的 `Read-Host` 让双击启动的窗口停留到按 Enter，便于看到“部署完成”。在简体中文 Windows 的正常 PowerShell 控制台中，5.1 会按控制台输出代码页显示中文。
