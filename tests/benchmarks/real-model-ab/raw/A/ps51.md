# 在中文 Windows 上，Windows PowerShell 5.1 会把带 BOM 的 UTF-8 `.ps1` 按 UTF-8 读取；脚本含中文时要保留 BOM。控制台输出则使用当前控制台输出代码页，中文 Windows 的正常控制台通常能显示中文。

把下面内容保存为 `H:\work\部署\deploy.ps1`，编码选择 **UTF-8 with BOM**（带签名的 UTF-8）。例如在 Windows PowerShell 5.1 里运行以下完整命令可创建目录并按该编码写入脚本：

```powershell
$path = 'H:\work\部署\deploy.ps1'
$directory = [System.IO.Path]::GetDirectoryName($path)
[System.IO.Directory]::CreateDirectory($directory) | Out-Null
$script = @'
#Requires -Version 5.1
$ErrorActionPreference = 'Stop'

try {
    Write-Host '开始部署'

    # 在这里加入实际部署步骤。

    Write-Host '部署完成：成功'
}
catch {
    Write-Host ('部署完成：失败 - ' + $_.Exception.Message) -ForegroundColor Red
    exit 1
}

Read-Host '按 Enter 键关闭窗口' | Out-Null
'@
$utf8WithBom = New-Object System.Text.UTF8Encoding($true)
[System.IO.File]::WriteAllText($path, $script, $utf8WithBom)
```

保存后直接双击 `deploy.ps1` 即可看到中文提示和最终状态；末尾的 `Read-Host` 会让窗口等到按 Enter 才关闭。若这台机器的 PowerShell 文件关联被改过，双击方式可能不会启动 PowerShell；可右键选择“使用 PowerShell 运行”。
