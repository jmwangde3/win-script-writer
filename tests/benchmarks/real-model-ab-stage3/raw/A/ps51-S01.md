# 在 Windows PowerShell 5.1 双击显示中文

把下面内容保存为 `H:\work\部署\deploy.ps1`。保存时选择 **UTF-8 with BOM（带 BOM 的 UTF-8）**；Windows PowerShell 5.1 读取含中文的 `.ps1` 时需要靠 BOM 正确识别 UTF-8。

```powershell
#Requires -Version 5.1

# 中文版 Windows 控制台通常使用代码页 936；让 PowerShell 按相同编码输出。
[Console]::OutputEncoding = [System.Text.Encoding]::GetEncoding(936)

Write-Host '开始部署'

# 在此处添加部署操作

Write-Host '部署完成'
```

双击运行时，控制台会显示“开始部署”，随后显示“部署完成”。若用编辑器另存文件，确认编码仍为 **UTF-8 with BOM**，不要选无 BOM 的 UTF-8。
