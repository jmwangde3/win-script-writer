在 Windows PowerShell 5.1 中，`.ps1` 若含中文，必须保存为 **UTF-8 with BOM**；否则 5.1 会按系统 ANSI 代码页读取无 BOM 文件，中文可能变乱码。脚本内容如下：

```powershell
#Requires -Version 5.1
$ErrorActionPreference = 'Stop'

Write-Host '开始部署'

# 在这里放置部署步骤

Write-Host '部署完成'
Read-Host '按回车键关闭窗口'
```

把以上内容保存到 `H:\work\部署\deploy.ps1`，并在编辑器的保存编码中明确选择 **UTF-8 with BOM**（也称 UTF-8 签名）。双击运行时，`Read-Host` 会让窗口停留，便于看到“开始部署”和“部署完成”。

中文能否显示还取决于 PowerShell 控制台的输出代码页；在简体中文 Windows 的常见默认控制台中，中文可正常显示。若双击 `.ps1` 打开的是编辑器而非运行脚本，这是 Windows 的文件关联行为；可从文件右键菜单选择“使用 PowerShell 运行”。
